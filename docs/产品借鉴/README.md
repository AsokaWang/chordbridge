# 弦桥 GitHub 产品借鉴资料索引

研究日期：2026-10-24。实现方向：.NET 后台与浏览器操作。本文汇总协议、功能想法和同类产品的研究入口，方便后续按需求选型，不要求整体采用任何一个项目。

**先看结论：优先复用成熟协议库，自己定义统一标签、连接事务和同周期组契约；参考工业网关的分层与调试界面，不把弦桥扩成完整 SCADA 或云平台。** 所有候选均未在弦桥中集成或设备实测，推荐不代表最终选型。公开源码、可商用代码、免费产品功能和商业扩展在各文档中分别说明。

## 从哪里开始

1. 阅读 [选型原则与落地顺序](00%20选型原则与落地顺序.md)，了解哪些可以考虑直接引用、哪些只借鉴设计，以及先验证什么。
2. 按下面的通讯协议文件选择驱动候选；RS232/422/485 是电气接口类别，不能与 Modbus 或 OPC 的应用协议层混为一谈。
3. 按功能设计文件阅读标签、模板、解析、调度和事务建议，保持自己的产品契约，不被某个 SDK 的模型限制。
4. 对照同类项目架构与界面，按模块吸收布局和分层，而不是直接复制整个系统。

## 优先候选速览

| 需求 | 优先研究入口 | 不能忽略的边界 |
| --- | --- | --- |
| 串口收发与自定义指令 | System.IO.Ports、RJCP SerialPortStream；TouchSocket 适配方案 | RS422/485 方向、总线与硬件驱动需实测；串口库不自动识别业务标签 |
| 自定义 Socket 报文 | TouchSocket、SuperSocket 与 .NET Socket/Pipelines | 消息分帧、会话关联和控制结果需自行定义；商业扩展不算开源核心 |
| Modbus RTU/TCP | NModbus、FluentModbus | 地址偏移、字节序、批量边界、RTU 独占事务不能省略 |
| OPC UA | OPC Foundation 官方 .NET 栈；Workstation.UaClient 对照 | 固定版本和许可证；订阅采样、发布、实际读取周期不同 |
| OPC DA | TitaniumAS 源码思路；QuickOPC 商业对照 | Windows COM/DCOM 与旧框架/组件位数限制，不能宣称 Linux 原生可用 |
| 统一标签及设备管理 | ThingsGateway、iioter/IoTGateway、Rapid SCADA | 上游采集变量不等于弦桥的数据/动作调用契约 |
| 可视化解析与脚本 | Node-RED、Serial Studio 设计；Jint/Roslyn 候选 | 非 .NET 项目只借鉴交互；脚本执行限制不等于操作系统沙箱 |
| 同周期定时组 | .NET PeriodicTimer/Channels 与连接执行器设计 | 不以 Hangfire recurring job 直接承诺 500 毫秒；非硬实时 |
| 后台与网页实时更新 | ASP.NET Core 后台服务与 SignalR | 页面刷新/断线不能重放控制；前端框架还没选定 |
| 主机资源与趋势 | 按平台的主机指标适配、进程指标、图表方案 | 浏览器机器不是被监视主机；缺失指标不能用零替代 |

表格是阅读路线，具体依据、许可证、可用版本与限制以下列分文件为准。项目名称不是已安装依赖清单。

## 如何理解本轮证据

本轮通过 GitHub 仓库、许可证、版本或提交记录、源码目录以及官方文档核查。各篇明确资料阅读与实际运行的区别；界面内容若来自功能说明或页面目录推导，会标为设计建议，不伪称操作过软件。

本轮没有运行第三方项目、安装依赖、向设备发指令、测试驱动、验证实际性能或完成许可证合规审计。后续依赖锁定必须重新核对具体版本及其许可证，商业授权不在本次采购范围内。

这些资料属于产品借鉴，不替代正式技术方案、实现任务或验收清单。建议按验证结果再选择具体组件，而不是一次性把表内所有库装进项目。

## 当前范围

用户已明确采用 .NET；具体 .NET 版本、前端框架、脚本语言和数据持久化方案仍待收敛。平台目标不等于实测支持清单，OPC DA 必须保留独立兼容性说明。其他尚未授权的文档和程序开发不会因本次研究自动启动。
